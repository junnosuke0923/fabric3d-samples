About this tool

This add-on turns an image into printable 3D geometry. There are two kinds: Pillar mode, which stands thin columns whose size follows the image's brightness, and Surface mode, which raises the image as a relief.

It targets the Stratasys J8 series and only ever builds shapes that need no support material — nothing ever faces downward.

Pillar mode and Surface mode

Which one to use depends on the texture you want.

  • Pillar mode: brightness becomes the height, thickness and density of columns. Good for brush-like textures and halftone shading.
  • Surface mode: the image is raised as a single continuous surface, like a print block or a relief.

Surface mode can also add pillars on top (Brush Composite).

Reading the panels

This tool lives in the sidebar on the right of the 3D View. If you cannot see the sidebar, press the N key. (View > Sidebar in the menu, or the small arrow at the top right, also opens it.)

Once it is open, pick the "Fabric 3D" tab from the vertical tabs on the right edge.

Panels appear as you go; they are never all shown at once.

  • Generation Settings: choosing an image and building the first preview.
  • Preview Adjust: appears once a preview exists. This is where you work.
  • Preview Options: fabric backing, camera and lighting — display only.
  • Export: appears after a final generate.

How to use it

1. Choose an image

Pick a PNG with transparency under Reference Data (Image) in the Generation Settings panel. Nothing is built where the image is transparent; brightness becomes height and thickness.

2. Build a preview

Press Generate Preview. It builds quickly at a coarse resolution, which is where you decide the shape.

3. Adjust

Use the Preview Adjust panel to change size, shape, thickness, height and color. Changes apply as you make them.

4. Final generate and export

Final Generate rebuilds it at high resolution; the Export panel writes OBJ or PLY.

You can close the Generation Settings panel once step 1 is done. The same settings live in the Preview Adjust panel, where you can change them while watching the result.

Work the edges (Lower at Edges / Edge Band Only)

Lower the columns towards the outline of the artwork, or keep only a band along it. However many islands there are, each is measured from its own edge.

Change the shape (Element Shape)

The cross-section: cylinder, hexagon, square, star, dome and more. The same artwork feels quite different just by changing this.

Circle

Align the columns (Orientation)

For elongated shapes, this sets which way they face: radial, tangential, or following the flow of brightness in the artwork. Changing the orientation changes the packing, so the count goes up or down. When following the flow, areas where the brightness barely changes have no direction to follow, so they fall back to the fixed orientation; darker colours need a larger change.

Pin

Lay them like scales (Tip Thickness)

Thins the far end of each element into a wedge that reads like a lying scale. The base stays on the fabric, so no downward face appears. It works on any cross-section, so it combines with the orientation.

1.00

Add a shape on top (Tip Part)

Stacks a second shape on each column: dome, cone, prism and so on. The width ratio is capped automatically against the base so nothing overhangs.

0.3

Set the thickness (Radius)

The thickness of one column. Thinner reads as finer, but the build minimum is 0.6mm across (0.3mm radius). Thicker means fewer columns, so decide it together with the density.

0.30mm

Thin out for tone (Thinning by Brightness)

Brighter parts lose columns at random. It is the halftone idea, so a single material still reads as light and shade. It only removes, so the spacing guarantee holds.

0.0

Vary it by location (Region Mask)

A second black-and-white image varies height, thickness and density by location. White areas stay as they are and darker areas fall towards the ratios you set, so one artwork can carry several textures.

1.0

Bulges the top face into a gentle mound. It loses the look of a slab and reads softer.

Split a large surface (Surface Split)

Surface mode builds one connected sheet. Printed large as it is, it behaves like a board: it will not bend, even on fabric. The fabric moves but the print does not, so it cracks where you bend it, or lifts away from the cloth.

That is what "Split Surface" is for. Cutting the surface into small tiles lets the fabric bend in the gaps between them. The pattern stays; only the movement comes back.

This figure: changing “Split the sheet”
Off

You will find "Split Surface" in the Preview Adjust panel. Tick it and these settings appear below.

  • Block Size: roughly how big one tile is. Smaller tiles mean a finer split and more bending.
  • Gap: the space between tiles. Wider bends better, but breaks up the pattern more. Narrower than 0.6mm and the tiles fuse when printed.
  • Pattern: Block (a grid), Random (a broken-up grid) or Voronoi (irregular, like cobblestones). Use Voronoi when the grid lines become distracting.
  • Phase X / Phase Y: shift where the cuts fall. Use them when a cut lands on an important part of the artwork.
  • Min Tile Size: removes tiles smaller than this. Useful for clearing the fragments left along the outline.
This figure: changing “Tile Size (mm)”
4mm

How far to split is a trade-off between how much you need it to bend and how the artwork should read. A finer split bends better, but as each tile gets smaller the artwork starts to look like a mosaic.

Bristle mode has no such setting. Bristles already stand apart one by one, so they never stiffen up the way a surface does.

Printing limits

Shapes that break the manual's conditions cannot be produced; the slider limits and warnings come from these numbers.

  • Minimum gap between elements: 0.6mm
  • Element size: 0.6mm to 15.0mm
  • Height: 0.4mm to 15.0mm
  • Sheet size: up to 460mm x 360mm
  • No downward-facing surfaces (overhangs). Every element sits on the bottom plane (Z=0).
  • The fabric must be a single flat sheet, 0.8-2.0mm thick, with no wrinkles, folds or seams. Sew after printing, not before.

Troubleshooting

  • Surface mode only produces a flat rectangle, or pillars stand outside the picture: the image has no transparency (alpha). Tick [Cut out the background] and the tool removes the background using the colour along the edges. When it decides it cannot - for example a pattern that runs to all four edges - it tells you so.
  • No pillars at all: either the image has no opaque area, or everything fell below the cutoff. Check Black/White under Brightness and the minimum-height cutoff under Height.
  • Slow preview: in Surface mode this is decided by resolution alone. Lower the preview resolution (384 is the default).
  • Replaced the image but nothing changed: press the reload button to the right of the image field.
  • No color, or everything black: check that the color mode is texture mapping, and switch the viewport to Material Preview or better.
  • Ragged edges: raise the column count under Size and Layout, or turn on Align to Contour under Contour (Snap Contour to Image in Surface mode).
  • Want to go back: the Settings History panel restores earlier settings.
